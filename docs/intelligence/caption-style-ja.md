## Model knowledge (not measured)
- Small Japanese shops write です・ます with soft friendly endings (〜です♪ / 〜ました！ / 〜ですね). Stacked keigo (させていただきます ×3) feels stiff; noun-stacks joined by ・ read like a catalog.
- The first line says what the news is (入荷 / 再入荷 / 色違い / price); many shops add a short seasonal remark (朝晩涼しくなってきましたね).
- Price as 「1,595円（税込）」 (consumer prices must be shown tax-inclusive). CTA like 「ご注文・ご質問はDM／Messengerからお気軽にどうぞ」.
- Short set phrases: 全国発送 / 代金引換OK / 残りわずか / 完売しました / 再入荷のお知らせ / 数量限定.
- 1-3 emoji or symbols (✨🌸♪); on Instagram 5-15 Japanese hashtags at the end (#和柄 #生地 #ハンドメイド #綿100).
- AI tells: 唯一無二 / 洗練された / 「〜があなたの毎日を彩ります」, dashes (—), translated-English phrasing, an emoji at the start of every line.

## Do
- です・ます + one soft ending (♪ / ！ / ね) per post. _[model_knowledge]_
- Line 1 = the news (入荷 / 再入荷 / 色違い); one idea per line, blank line between blocks. _[model_knowledge]_
- Price 「1,595円（税込）」; material only 「綿100%」. _[owner rule + model_knowledge]_
- Colours in Japanese words: 青磁色×藍鼠 / 黄土色×グレー / 茶×赤 / 黒. _[catalog colours, translated]_
- CTA as a friendly invitation: 「Messengerからお気軽にどうぞ」. _[model_knowledge]_
- Instagram: 5-15 Japanese hashtags at the end; Facebook: 0-3. _[model_knowledge]_
- Write Japanese as its own post, not a line-by-line translation of the English. _[measured contrast with v1]_

## Don't
- No 体言止め chains like 「同じ柄・2色・税込・…」 (catalog/robot voice). _[measured contrast: v1 JA block does this in every post]_
- No 🇯🇵/🇬🇧 flag-labelled translation lines. _[measured contrast with v1]_
- No stacked keigo (させていただきます ×3, 誠に…). _[model_knowledge]_
- No AI praise: 唯一無二, 洗練された, 上質な, 「毎日を彩ります」. _[model_knowledge]_
- No dashes (—), no English-style quotes or colons in sentences. _[model_knowledge]_
- Never 細布, never width/length, never supplier codes. _[owner rule]_
- Never copy another shop's wording (copy guard: 12 Japanese characters). _[owner rule]_
