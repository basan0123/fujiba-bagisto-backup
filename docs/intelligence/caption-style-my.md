## Model knowledge (not measured)
- Myanmar Facebook sellers write spoken Burmese (…ပါတယ် / …နော် / …မယ်), not literary Burmese (…သည် / ၏ / ၍ / …ပါသည်), which reads like a news report or a machine translation. Women sellers end lines with ရှင့်/ရှင်, men with ခင်ဗျာ/ဗျ.
- Customers are addressed warmly: Customer လေးတို့, အစ်မတို့, ညီမလေးတို့; the diminutive လေး (အထည်လေး, အရောင်လေး) is everywhere and sounds friendly.
- Typical first lines: New Arrival, Instock ပြန်ရပါပြီ, ရောက်ပါပြီနော်, ဈေးလျှော့; fancy-font headers (𝐍𝐞𝐰 𝐀𝐫𝐫𝐢𝐯𝐚𝐥) are common but invisible to search.
- Price as "¥1,595" or "1595 ယန်း"; CTA via Inbox / Page Messenger, "Comment မှာ code ရေးပေးပါ", phone/Viber. Hiding the price ("ဈေးနှုန်း inbox") is common but loses buyers.
- Delivery/payment lines: အိမ်ရောက်ငွေချေ (COD), ဂျပန်တစ်နိုင်ငံလုံး ပို့ပေးပါတယ်, ပို့ခ; stock: Stock နည်းနည်းပဲ ကျန်တော့တယ်, ပြတ်သွားပါပြီ, ပြန်ရောက်ပါပြီ.
- Since Myanmar's 2019 switch most new posts are Unicode, but Zawgyi still appears from older phones/fonts (Facebook converts some on display). Always publish Unicode.
- AI tells in Burmese: literary endings (သည်/၏), flawless formal grammar with no particles, word-for-word English idioms, long praise lists, em dashes.

## Do
- Spoken endings …ပါတယ် / …ပါမယ် / …နော် with the page voice ရှင့်/ရှင်. _[measured (n=3, own page) + model_knowledge]_
- Code + price in the first 2-3 lines (before "See more"). _[model_knowledge]_
- Mix English shop words in Latin letters: New arrival, Instock, Sold out, Order, COD. _[measured (n=3, own page)]_
- Warm address: Customer လေးတို့ / အစ်မတို့; diminutive လေး. _[model_knowledge]_
- Clear price "¥1,595"; COD + delivery-in-Japan line. _[measured (n=3, own page) + model_knowledge]_
- 2-5 emoji, hearts are fine (🥰💕✨🌸). _[measured (n=3, own page) + model_knowledge]_
- Unicode only (checked by the Zawgyi heuristic before anything is saved). _[owner rule]_

## Don't
- No literary register (သည် / ၏ / ၍ / မည် / ပါသည်). _[model_knowledge]_
- No em dashes or Japanese glosses (再入荷待ち) inside Burmese lines. _[measured contrast with v1 sold-out line]_
- Don't repeat the same CTA sentence twice in one post. _[measured contrast with v1]_
- Don't hide the price behind "inbox". _[model_knowledge]_
- No Zawgyi, no mixed encodings. _[owner rule]_
- Never length/width (မီတာ) or supplier codes. _[owner rule]_
- Never copy another seller's sentences (copy guard: 20 Burmese characters). _[owner rule]_
